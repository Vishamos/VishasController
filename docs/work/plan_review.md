## 노션에 적을 것
1. 아래 "결정됨"에서 `(노션 미반영)` 표시가 붙은 항목 전부.
2. 트레이 상주와 알림(알림 풍선, 안 읽음 점)이 노션에 없다. 노션의 탭 창은 트레이에서 여는 창이라는 것(명세 02 §1.2).
3. 치지직 탭 문장이 "상태, 채팅,"에서 끊겨 있다. 1단계 범위(채팅·상태 받기)로 채우면 된다.
4. "준비 중"(아직 연결 기능이 없는 것)은 노션의 3색에 없다. ⚫로 따로 둠(명세 02 §2.3). 노션 "각 탭"의 🟢🟡🔴에 ⚫를 추가할 것.
5. 노션의 시냅스·페이스·바디 탭은 종합 탭의 프로그램 표 줄로 옮겼다(연결 체크, On/Off, 파일 실행). 노션 탭 목록을 종합·OBS·치지직·비샤모스로 고칠 것.
6. 기획 태그가 없다. 컨트롤러 항목에 태그를 붙이면(예: `[Controller-Tab-OBS]`) worklist·명세 근거를 태그로 바꾼다.

## 결정됨
- (2026-11-22, VishaSynapse에서 결정) C# .NET 8 이상 WinForms 트레이 앱으로 만들고, VishaSynapse의 WebSocket 클라이언트(JSON)로 접속한다. 이유: 트레이 상주가 쉽고, Unity는 상시 렌더링이라 송출 PC에 부담 (시작자료 §1)
- (2026-11-25, 노션 미반영) 1단계 알림 방식: 트레이 아이콘 4색(초록·주황·빨강·회색)과 안 읽음 점, 알림 풍선 4초 묶음(채팅 창을 보고 있으면 생략, 메뉴로 끄기), 상태 알림은 항상, 알림음 기본 꺼짐, 최근 1000개 채팅 창(X는 숨기기), 역할 색(스트리머 보라·관리자 초록), 이모지는 `:코드:` 글자 (명세 01 §3∼§6)
- (2026-11-25, 노션 미반영) 1단계 연결 동작: 서버 주소는 `%AppData%\VishasController\settings.json`(기본 `ws://localhost:4000`), 접속 10초·등록 응답 10초 제한, 재접속 1초부터 2배·최대 30초(등록 성공 뒤 1초로), 404면 60초마다, 컨트롤러도 30초 ping·30초 응답 제한 (명세 01 §2, §7)
- (2026-11-26) 노션에 컨트롤러 기록이 없으므로 `VishasController_시작자료.md`를 명세 01·plan_review·worklist로 옮겨 기준으로 쓴다. 시작 자료는 옮긴 뒤 삭제했다(커밋 b2943ea에 있음)
- (2026-11-26) 작업 흐름을 `visha-common` 플러그인(main-thread, developer·qa·security 서브에이전트)으로 진행한다. developer는 `simple-test`(솔루션 빌드)로 확인하고, 트레이 앱·TestServer 화면 확인은 사용자가 한다. 노션 해당 없음
- (2026-11-26) 테스트 프로젝트는 지금 만들지 않는다. 지금 단위 테스트 대상이 메시지 해석(`Messages.cs`) 정도라 NuGet 의존성과 프로젝트 추가 비용이 더 크다. 로직이 늘어나는 2단계에서 다시 정한다(worklist Test-1). 노션 해당 없음

- (2026-11-26) 노션의 탭 구성(종합, OBS, 치지직, 시냅스, 페이스, 바디, 비샤모스)을 지금 만든다. 서버 쪽이 필요한 기능은 빼고 UI 자리만 만든다(비활성). 이미 있는 서버 연결·치지직 채팅은 시냅스·치지직 탭에 연결한다. 채팅 창은 치지직 탭으로 들어간다 (명세 02)
- (2026-11-26) 트레이 상주·알림은 유지하고, 트레이에서 탭 메인 창을 연다. 트레이 아이콘 색은 그대로 두고 탭 상태만 노션 3색(🟢🟡🔴)을 쓴다. 트레이 3색 통일은 Spec-2에서 (명세 02 §1.2, §2.7). 사용자가 "기능이 연결되지 않아도 UI 구성부터"라고 해서 메인 스레드가 권장안으로 정함 — 바꾸려면 알려 주세요

- (2026-11-26, 2차) 탭은 종합·OBS·치지직·비샤모스 4개. 시냅스·페이스·바디는 종합 탭 프로그램 표의 줄(연결 상태, On/Off, 파일 실행, 시냅스는 주소·다시 접속 추가). 준비 중은 글자 대신 ⚫. 서버 주소는 탭에 표시하지 않는다(가린 형태도 없음, "주소 설정…" 창에서만). 트레이 왼쪽 클릭은 메인 창, 오른쪽 클릭은 빠른 설정(창 열기·채팅 알림 풍선·알림음·종료). 파일 실행 경로는 PC마다 달라서 설정에 두고, 경로가 없으면 실행 버튼을 숨긴다(Proc-1에서 구현) (명세 02 §1.2, §1.5, §2.3, §3.1a)
- (2026-11-26, 3차) 상태를 확인하는 각 대상(시냅스·바디·페이스·OBS·치지직·비샤모스)을 **모듈**이라 부른다. 코드 `Module`/`ModuleState`, 태그 `[vc-module-…]`. Synapse 규약의 "클라이언트"(시그니처를 가진 접속자)와 구분한다
- (2026-11-26, 3차) 종합 탭을 **시냅스 탭**으로 바꾼다. 탭 점은 서버 연결 상태, 위쪽에 시냅스 자신의 정보, 아래 표에는 시냅스가 보는 모듈. 로그 탭을 추가한다(노션 `[vc-window]`, 합친 로그 + 필터). 프리셋 위치와 ⏻·⚙️의 의미는 사용자가 노션에 정리 중
- (2026-11-26, 3차) 페이스 줄도 ⏻를 둔다(모듈마다 같은 형태로 두어 코드를 단순하게). iPhone이라 실행할 수 없으므로 실행 경로가 없을 때의 규칙(숨김 또는 비활성)을 그대로 따른다
