# 기획 검토 (plan_review)

마지막으로 읽은 노션 판: 2026-11-26 12:36 UTC (`VishaSTD / VishasController`. `[vc-preference]` 대조만 함)

## 노션에 적을 것
1. 1단계 알림 방식(2026-11-25): 트레이 아이콘 4색(초록·주황·빨강·회색)과 안 읽음 점, 채팅 알림 풍선 4초 묶음(채팅 창을 보고 있으면 생략), 알림음 기본 꺼짐, 최근 1000개 채팅, 역할 색(스트리머 보라·관리자 초록), 이모지는 `:코드:` 글자. "중요 경고"는 기본 켬 (명세 01 §3∼§6, 02 §1.2)
2. 1단계 연결 동작(2026-11-25): 기본 주소 `ws://localhost:4000`, 접속 10초·등록 응답 10초 제한, 재접속 1초부터 2배·최대 30초(등록 성공 뒤 1초로), 41 미지원(404)이면 60초마다, 컨트롤러도 30초 ping·30초 응답 제한 (명세 01 §2, §7)
3. 치지직 탭 문장이 "상태, 채팅,"에서 끊겨 있다. 1단계 범위(채팅·상태 받기)로 채우면 된다.
4. `[vc-simple_module]`: 시냅스의 ⚙️에는 서버 주소와 "컨트롤러가 켜지면 자동 실행"이 들어간다(노션의 "시냅스가 켜지면 자동으로 실행"은 바디·페이스용). "다시 접속" 버튼은 없다(자동 재접속). ⏻는 실행만 하고 종료는 하지 않으며, 실행 중이면 누를 수 없다.
5. 태그 `[vc-module-controll]`의 철자(`control`)를 고칠지. 태그 이름은 한번 정하면 바꾸지 않으므로 지금 정하는 게 좋다.
6. 로그 탭: 서버 주소·채팅 내용·닉네임은 남기지 않는다.
