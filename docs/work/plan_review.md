## 결정됨
- (2026-11-22, VishaSynapse에서 결정) C# .NET 8 이상 WinForms 트레이 앱으로 만들고, VishaSynapse의 WebSocket 클라이언트(JSON)로 접속한다. 이유: 트레이 상주가 쉽고, Unity는 상시 렌더링이라 송출 PC에 부담 (시작자료 §1)
- (2026-11-25, 노션 미반영) 1단계 알림 방식: 트레이 아이콘 4색(초록·주황·빨강·회색)과 안 읽음 점, 알림 풍선 4초 묶음, 알림음 기본 꺼짐, 최근 1000개 채팅 창, 이모지는 `:코드:` 글자 (시작자료 §6)
- (2026-11-26) 작업 흐름을 `visha-common` 플러그인(main-thread, developer·qa·security 서브에이전트)으로 진행한다. developer는 `simple-test`(솔루션 빌드)로 확인하고, 트레이 앱·TestServer 화면 확인은 사용자가 한다. 노션 해당 없음
- (2026-11-26) 테스트 프로젝트는 지금 만들지 않는다. 지금 단위 테스트 대상이 메시지 해석(`Messages.cs`) 정도라 NuGet 의존성과 프로젝트 추가 비용이 더 크다. 로직이 늘어나는 2단계에서 다시 정한다(worklist Test-1). 노션 해당 없음
