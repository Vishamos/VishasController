# 01. 치지직 채팅 수신 (1단계)

- **다루는 것:** 서버 접속·등록·재접속, `chzzk.chat`·`chzzk.status` 받기, 트레이 아이콘·알림·채팅 창·설정
- **다루지 않는 것:** 컨트롤러가 서버로 보내는 메시지(등록 제외), 관리 기능(2단계), 이모지 이미지 표시, 서버 프로세스 시작·종료
- **근거 노션:** 없음(노션 `VishaSTD / VishasController`에 기록 없음). 2026-11-26 시작 자료(VishaSynapse에서 옮긴 자료, 2026-11-25. 삭제됨, 커밋 b2943ea의 `VishasController_시작자료.md`)에서 옮겼다. 아래 "시작자료 §N"은 그 문서의 절이다.
- **명세 02로 바뀐 부분:** 채팅 창은 메인 창의 치지직 탭이 되었다. §4.4·§5.2의 "채팅 창을 보고 있을 때"는 명세 02 §4.1, §4.6의 메뉴 "채팅 창 열기"는 "창 열기"(명세 02 §1.2∼§1.3), §6은 명세 02 §3.5, §5.2의 알림 끄기는 명세 02 §1.2("알림"·"중요 경고" 분리), §7 설정 위치는 명세 02 §5를 따른다.
- **참조 규약:** `Vishamos/VishaSynapse:docs/protocol/README.md @59d27fe`
  - §1 접속, §2 시그니처, §3 등록, §4.1 JSON, §5a 치지직 → 컨트롤러, §6 에러와 연결 종료, §7 연결 유지, §8 메시지 크기
  - 메시지 형식·값은 여기 옮겨 적지 않는다. 규약이 바뀌면 이 머리말의 해시를 갱신하고 영향을 본다.

## 2. 서버 접속

| 항목 | 내용 | 구분 | 근거 |
|---|---|---|---|
| 2.1 주소 | 설정 파일의 `ServerUrl`, 기본값 `ws://localhost:4000`. `ws://`·`wss://`만 받는다 | 확정(대화) | plan_review 2026-11-25 |

| 2.4 등록 응답 대기 | 10초 안에 응답이 없으면 끊고 다시 접속(서버 한도 30초보다 짧게) | 확정(대화) | plan_review 2026-11-25 |

| 2.8 버리는 메시지 | 64KB 초과, 바이너리, 깨진 JSON, 모르는 `type`. 연결은 유지 | 확정 | 규약 §8, §5a "주의" |

## 8. 확인 방법

- 빌드: `simple-test`
- 화면 동작: `tools/TestServer`(VishaSynapse 대역)로 사용자가 확인한다.
  ```
  dotnet run --project tools/TestServer            # ws://localhost:4000
  dotnet run --project tools/TestServer -- --no41  # 41을 모르는 서버 흉내(404)
  ```
  콘솔 명령: `m` 채팅, `s` 스트리머, `g` 채팅 관리자, `e` 이모지, `b 20` 몰아 보내기, `auto` 자동 채팅, `c`/`d`/`a`/`x` 치지직 상태(connected/disconnected/auth_required/disabled), `kick` 강제 끊기, `big` 64KB 초과, `u` 모르는 type, `q` 종료.
- 실제 연동: VishaSynapse `npm start` → 치지직 `connected` → 방송 채팅 수신.
