# 02. 메인 창 탭 구성 (UI 골격)

- **다루는 것:** 채팅 창을 대신하는 메인 창, 탭 4개의 배치, 종합 탭의 프로그램 표, 탭 상태 표시. 이미 있는 기능(서버 연결, 치지직 채팅·상태)은 연결하고, 나머지는 **자리만 만든다**(비활성 컨트롤).
- **다루지 않는 것:** OBS·Vishamos 제어, 프리셋 저장, 페이스·바디 연결 상태 받기, 프로그램 On/Off·파일 실행 동작, 서버 쪽 새 메시지. 모두 VishaSynapse 쪽 결정 뒤에 한다(plan_review 보류).
- **근거 노션:** `VishaSTD / VishasController` (2026-11-26 01:11 판)
- **참조 규약:** 없음(새 메시지 없음). 서버 메시지는 명세 01을 따른다.

## 5. 코드 구조

- `UI/ChatForm.cs`를 `UI/MainForm.cs`(창, 탭, 상태 표시줄)와 `UI/Tabs/`의 탭별 `UserControl`로 나눈다. 채팅 목록은 `ChatTab`으로 옮긴다.
- 탭 상태 색은 `TrayIcons.ColorOf(Health)`를 그대로 쓴다(`Health.Idle` = 회색). 준비 중(⚫)은 검정 점으로 그린다.
- 2차 변경(UI-4): `SynapseTab`·`PendingTab`(페이스·바디)은 없애고 내용을 `OverviewTab`의 프로그램 표 줄로 옮긴다. 시냅스 줄의 다시 접속·주소 설정은 기존 `SynapseTab` 이벤트(`ReconnectRequested`, `SettingsRequested`)를 그대로 쓴다.
- `TrayContext`는 `ChatForm` 대신 `MainForm`을 쓰고, 탭 상태는 `MainForm`에 상태 값을 넘겨 갱신한다. 연결 로직(`SynapseClient`)은 바꾸지 않는다.

구현 때 세운 가정(developer 보고, 확인 대기):
- 시냅스 탭 주소는 호스트와 경로를 가리고, 기본 포트면 포트도 생략한다. 형식 오류면 "(주소 형식 오류)"
- 상태 경고·시작 안내 풍선을 클릭하면 마지막에 보던 탭으로 연다(채팅 풍선만 치지직 탭)
- 🟡는 `Health.Warning` 색이라 실제로는 주황으로 보인다
- 치지직 탭 안 읽은 수는 트레이 안 읽음과 같은 값이다. 다른 탭으로 창을 열면 지워지지 않는다
- 아래 상태 표시줄은 명세 01 색 기준이라 탭 점과 색이 다를 수 있다(주소 오류: 탭 빨강·표시줄 회색, 등록 뒤 상태 대기: 탭 주황·표시줄 회색)
- 치지직 탭으로 돌아오면 맨 아래로 스크롤한다
