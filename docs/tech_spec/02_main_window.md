# 02. 메인 창 탭 구성 (UI 골격)

- **다루는 것:** 채팅 창을 대신하는 메인 창, 탭 7개의 배치, 탭 상태 표시. 이미 있는 기능(서버 연결, 치지직 채팅·상태)은 연결하고, 나머지는 **자리만 만든다**(비활성 컨트롤).
- **다루지 않는 것:** OBS·Vishamos 제어, 프리셋 저장, 페이스·바디 연결 상태 받기, 서버 쪽 새 메시지. 모두 VishaSynapse 쪽 결정 뒤에 한다(plan_review 보류).
- **근거 노션:** `VishaSTD / VishasController` (2026-11-26 01:11 판)
- **참조 규약:** 없음(새 메시지 없음). 서버 메시지는 명세 01을 따른다.

## 3. 탭 내용

비활성 컨트롤은 `Enabled = false`이고, 누를 수 없다는 것이 보이게 둔다. 목록에는 가짜 항목을 넣지 않고 비워 둔다(방송 화면에 잘못된 정보가 보이지 않게).

| 탭 | 내용 | 연결 | 근거 |
|---|---|---|---|
| 3.1 종합 | 위: 프로그램별 상태 표(이름, 색 점, 상태 글자: 시냅스, 치지직, OBS, 페이스, 바디, 비샤모스). 아래: "프리셋" 묶음 — 프리셋 목록(비어 있음), 버튼 "적용"·"새로 만들기"·"편집"·"삭제"(비활성), 안내 "OBS 장면과 비샤모스 월드·캐릭터를 묶어 한 번에 바꿉니다(준비 중)" | 상태 표의 시냅스·치지직 줄만 실제 상태 | 노션 종합 탭, "프리셋 저장" |
| 3.2 OBS | "장면" 목록(비어 있음) + "전환" 버튼, "마이크 음소거" 체크 버튼, "녹음 시작" 버튼, "방송 상태: -" 글자. 모두 비활성, 위에 "준비 중" 안내 | 없음 | 노션 OBS 탭 |
| 3.3 치지직 | 지금 채팅 창의 채팅 목록 전체(열, 역할 색, 1000개, 스크롤, 오른쪽 클릭 메뉴) | 명세 01 §6 그대로 | 노션 치지직 탭, 명세 01 |
| 3.4 시냅스 | 서버 주소(가린 형태: `ws://***:4000`처럼 호스트를 가림), 연결 상태 글자, 연결 번호, 버튼 "다시 접속"·"서버 주소 설정…"(트레이 메뉴와 같은 동작) | 실제 | 노션 시냅스 탭(비어 있음), coding-rule §7 |
| 3.5 페이스 | 연결 상태 글자 "-" 와 "준비 중" 안내 | 없음 | 노션 페이스 탭 |
| 3.6 바디 | 연결 상태 글자 "-" 와 "준비 중" 안내 | 없음 | 노션 바디 탭 |
| 3.7 비샤모스 | "장면" 목록(`[Vishamos-Space]`, 비어 있음) + "선택" 버튼, "캐릭터 배치" 묶음(비어 있음). 모두 비활성, "준비 중" 안내 | 없음 | 노션 비샤모스 탭 |

## 5. 코드 구조

- `UI/ChatForm.cs`를 `UI/MainForm.cs`(창, 탭, 상태 표시줄)와 `UI/Tabs/`의 탭별 `UserControl`로 나눈다. 채팅 목록은 `ChatTab`으로 옮긴다.
- 탭 상태 색은 `TrayIcons.ColorOf(Health)`를 그대로 쓴다(`Health.Idle` = 회색).
- `TrayContext`는 `ChatForm` 대신 `MainForm`을 쓰고, 탭 상태는 `MainForm`에 상태 값을 넘겨 갱신한다. 연결 로직(`SynapseClient`)은 바꾸지 않는다.
